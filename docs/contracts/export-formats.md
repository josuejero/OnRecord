# Export Formats

> Placeholder: define the accepted file formats for exporting recaps, labels, and transcripts.

## Formats to track

- `json`: Structured payload with arrays of entries and metadata, best for downstream APIs.
- `csv`: Tabular view of key fields (speaker, timestamp, label, confidence) that can be opened in spreadsheets.
- `jsonl`: Line-delimited JSON used for streaming exports and multi-record uploads.
